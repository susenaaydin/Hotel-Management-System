# Hotel Management System

.NET Framework ve SQLite tabanlı Otel Yönetim Sistemi (Hotel Management System) masaüstü uygulaması.

## 📋 Proje Bilgileri

- **Platform:** Windows Desktop (.NET Framework 4.7.2)
- **Veritabanı:** SQLite (`hotel_management.db`)
- **ORM / Veri Katmanı:** Entity Framework 6 / SQLite Data Provider

## 🚀 Çalıştırma

1. Projeyi klonlayın veya indirin.
2. `hotel.com` klasörü altındaki `HotelManegmentSystem.exe` dosyasını çalıştırarak uygulamayı başlatabilirsiniz.

```bash
# Repository'yi klonlamak için:
git clone https://github.com/susenaaydin/Hotel-Management-System.git
```

> **Not:** Uygulamanın sorunsuz çalışması için `hotel.com` klasöründeki bağımlılık (.dll) ve yapılandırma (.config) dosyalarının `.exe` ile aynı dizinde bulunması gerekir.
